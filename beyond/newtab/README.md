# Nouvel onglet Grok Night

Un **thème** Firefox ne peut pas poser un fond + du texte sur `about:newtab`.
Cette mini-extension le fait : `chrome_url_overrides.newtab`.

## Installer (en plus du thème)

1. `about:debugging#/runtime/this-firefox`
2. **Charger un module temporaire**
3. `beyond/newtab/manifest.json`

Ctrl+T : trou noir + raccourcis grok.com / Grok Build.
